# CET-6 v13 问题处置与回归记录

> 基线：`game_v12/PROBLEM.md`。本文件记录 v13 的核查、修复和验证结果；v12 保持不变。原清单没有 P2，因此编号沿用 P1、P3-P12。

## 处置结果

- **P1 已修复｜跳过后锁死**：第 20、30、40 词跳过并完成世界转场后会释放答题锁，输入与提交均恢复。
- **P3 已修复｜极光冰原桌面性能**：按画布像素预算分档，并复用同帧地形采样。1440x900、DPR 2 的真实 GPU Chrome 测试由 v12 的 `36.875 FPS` 提升至 v13 的 `60.002 FPS`；Canvas mock 绘制调用减少 57%，`groundY()` 调用减少 65%。390x844 手机尺寸仍使用完整细节档。
- **P4 已修复｜答错后速度恢复**：连击清零时同步刷新目标速度，实测速度由 `1.244` 立即回落至 `1.044`。
- **P5 已修复｜通关特效冻结**：结算时停止计时器、角色和环境循环，但保留结算环、烟花与粒子动画。
- **P6 已修复｜10 题极速奖励被转场遮挡**：奖励在世界转场结束后再完整播放；退出、重开或运行代次变化时会丢弃旧奖励。
- **P7 已修复｜中央文字重叠**：连击、技能与状态提示改为 FIFO 单通道队列，同一时刻只显示一条；转场期间暂停，退出和结算时清空。
- **P8 已修复｜全部静音状态不同步**：总静音会同步 BGM 内部状态和所有 `Audio` 实例；取消后 BGM 按钮一次点击即可恢复。
- **P9 已修复｜重试重复切歌**：重新开始只触发一次曲目选择与播放。
- **P10 已修复｜启动预载过多**：世界曲目改为首次需要时惰性创建，未启用的 `Volatile_Reaction.mp3` 不再进入播放配置。实测启动只创建当前菜单曲目的音频实例，进入关卡后才创建首个世界曲目实例。
- **P11 已修复｜结算页后台循环**：失败或胜利后会停止主计时、角色和环境更新，不再继续消耗游戏运行循环。
- **P12 已修复｜转场时仍可输入**：世界转场期间禁用输入和提交，结束或取消时按当前运行状态恢复。

## 相关边界修复

- S Rank 提示移入胜利层，避免被结算遮罩挡住。
- 恰好 5 或 10 词的短关卡会先完整播放本次极速奖励，再显示胜利页。
- 失败或胜利层挂载前清空旧中央提示，避免上一运行的文案延迟出现。
- 10 题累计 `10.000s` 会触发二级奖励，`10.001s` 不触发，边界符合规则。

## 回归验证

- 真实 Chrome 自动化覆盖：20/30/40 词跳过、5/10 题极速奖励、答错降速、总静音恢复、重试切歌和结算动画。
- 九个世界在 1440x900 桌面和 390x844 手机画布均非空，无横向溢出。
- 首屏惰性音频、世界曲目加载和控制台异常均已检查；测试过程未发现 JavaScript 异常。
- 全量 JavaScript 通过 `node --check`，资产构建脚本通过 `sh -n`。

## 仍需人工体验

自动化只能确认功能与性能边界。长时间游玩时的音乐衔接、不同设备上的音量平衡、低端设备的冰原稳定帧率，以及密集特效是否过强，仍建议在实际浏览器中观察；这些是体验校准项，不是当前已复现故障。
